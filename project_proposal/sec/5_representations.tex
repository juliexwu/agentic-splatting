\section{Representations}
\label{sec:representations}

The Prefiltering agent passes a subset of the original input frames into the Actor/Critic cycle. The Actor agent passes the rendered scene to the Critic agent as a set of 3D Gaussians. The Critic agent will represent feedback in a structured .json format, such that the Actor agent can easily interpret it and determine how to iterate based on the feedback.
