\section{Expected Outcomes}
\label{sec:expected_outcomes}

We expect to create an end-to-end agentic Gaussian Splatting pipeline that can take in a series of 2D images (or a video) and output a high quality 3D representation, even for unseen views. The prefiltering, actor, and critic agents will work together to select high quality inputs, optimize a config file for the pipeline, and synthesize the final reconstruction.
